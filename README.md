A classic, lightweight **Snake** arcade game built with pure HTML5 Canvas and vanilla JavaScript. Zero dependencies, instant loading, and built-in retro styling.

## 🕹️ Controls

| Action | Keys |
| :--- | :--- |
| **Move Up** | `Arrow Up` or `W` |
| **Move Down** | `Arrow Down` or `S` |
| **Move Left** | `Arrow Left` or `A` |
| **Move Right** | `Arrow Right` or `D` |
| **Restart Game** | `Spacebar` (when Game Over) |

---

## 🌟 Features

* **Arcade Aesthetic:** Dark CRT-themed UI with clean glowing neon borders and a custom scoreboard tracker.
* **High Score Storage:** Saves your personal best locally using `localStorage` so your record stays intact when you refresh.
* **Pure Vanilla Stack:** Built with raw HTML5 Canvas and JavaScript—no heavy frameworks, bundlers, or extra installations needed.
* **GitHub Pages Ready:** Hosted instantly right from the repository.
